# VoiceMind Java Core 架构设计文档

## 项目概述

VoiceMind Java Core 是一个基于Spring AI框架构建的智能语音助手后端系统，提供多种AI聊天模式、工具集成、RAG检索增强生成等功能。系统采用模块化设计，支持多种AI模型和工具调用能力。

## 技术栈

- **框架**: Spring Boot 3.5.6
- **Java版本**: Java 21
- **AI框架**: Spring AI 1.0.0
- **AI模型**: 通义千问 (DashScope)、Gemini
- **文档工具**: Knife4j (Swagger)
- **工具库**: HuTool、Jsoup、iText PDF
- **构建工具**: Maven

## 核心模块设计

### 1. 控制器层 (Controller Layer)

#### 1.1 AiController
- **职责**: 提供AI聊天相关的REST API接口
- **主要功能**:
  - 基础AI聊天 (`/ai/chat/do`)
  - 带报告的AI聊天 (`/ai/chat/report`)
  - RAG增强聊天 (`/ai/chat/rag`)
  - 工具增强聊天 (`/ai/chat/tools`)
  - MCP协议聊天 (`/ai/chat/mcp`)
  - SSE流式聊天 (`/ai/chat/sse`)

#### 1.2 HealthController
- **职责**: 提供系统健康检查接口
- **功能**: 监控系统运行状态

#### 1.3 MultiController
- **职责**: 提供多模态处理接口
- **功能**: 处理图像、文本等多种输入类型

### 2. 应用服务层 (Application Layer)

#### 2.1 OrderApp
- **职责**: 核心AI聊天应用服务
- **核心功能**:
  - 多轮对话记忆管理
  - 多种AI聊天模式支持
  - 流式响应处理
  - 结构化输出生成

#### 2.2 ImageApp
- **职责**: 图像处理应用服务
- **功能**: 图像识别、处理、分析

### 3. AI服务层 (AI Service Layer)

#### 3.1 模型支持
- **通义千问 (DashScope)**: 主要AI模型
- **Gemini**: 备用AI模型
- **模型配置**: 通过配置文件管理API密钥和模型参数

#### 3.2 ChatClient
- **功能**: 统一的AI聊天客户端
- **特性**:
  - 支持多种Advisor模式
  - 工具调用能力
  - 流式响应
  - 会话记忆

### 4. 工具集成层 (Tool Integration Layer)

#### 4.1 文件操作工具
- **FileOperationTool**: 文件创建、读取、写入、删除
- **PDFGenerationTool**: PDF文档生成
- **ResourceDownloadTool**: 资源下载

#### 4.2 网络工具
- **WebSearchTool**: 网络搜索
- **WebScrapingTool**: 网页内容抓取

#### 4.3 系统工具
- **TerminalOperationTool**: 终端命令执行
- **TerminateTool**: 进程终止

### 5. RAG知识库层 (RAG Layer)

#### 5.1 向量存储
- **OrderAppVectorStoreConfig**: 向量存储配置
- **支持**: 内存向量存储、PgVector等

#### 5.2 文档处理
- **OrderAppDocumentLoader**: 文档加载器
- **MyTokenTextSplitter**: 文本分割器
- **MyKeywordEnricher**: 关键词增强器

#### 5.3 查询处理
- **QueryRewriter**: 查询重写器
- **QuestionAnswerAdvisor**: 问答增强器

### 6. 基础设施层 (Infrastructure Layer)

#### 6.1 异常处理
- **GlobalExceptionHandler**: 全局异常处理器
- **自定义异常类**: 
  - `ActionExecutionException`
  - `CustRuntimeException`
  - `InvalidRequestException`
  - `LLMServiceException`

#### 6.2 配置管理
- **CrossConfig**: 跨域配置
- **Knife4jConfig**: API文档配置
- **FileConstant**: 文件常量定义

#### 6.3 日志和监控
- **MyLoggerAdvisor**: 自定义日志增强器
- **ReReadingAdvisor**: 推理增强器

## 数据流设计

### 1. 请求处理流程

```
客户端请求 → 控制器 → 应用服务 → AI服务 → 工具/RAG → 响应
```

### 2. AI聊天流程

```
用户输入 → 会话管理 → 查询重写 → 向量检索 → AI模型 → 工具调用 → 响应生成
```

### 3. RAG增强流程

```
用户查询 → 查询重写 → 向量检索 → 上下文增强 → AI生成 → 结果返回
```
